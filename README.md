## Bird Watch C

Welcome to Bird Watch, a photography website for birds!

Current Features:
- Main page
- About
- Featured bird images
- Book a shoot form that sends an email to the photographer
- Header and footer section for nav links and info

The Next.js App Router version is in `next-project`. To run it locally:

```powershell
cd next-project
npm run dev
```

Then open http://localhost:3000.

The original Vite app remains in `vite-project` as a fallback while the Next.js version is being tested.
Both versions currently use the same local sample bird data; database integration is a separate next step.

Built as a learning project.
