## Bird Watch C
### Since site is not officially launched yet, must start a local Vite server to visit site (eg. http://localhost:5173/)

Welcome to Bird Watch, a photography website for birds!

Current Features:
- Main page
- About
- Featured bird images
- Book a shoot form that sends an email to the photographer
- Header and foot section for nav links and info

Currently runs on Vite + React and Javascript (JSX) for functionality
(Built as a learning project)
